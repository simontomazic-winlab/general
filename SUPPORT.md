# Support — Suspicious Email Reporter

Need help with the **Suspicious Email Reporter** add-on? This page covers the basics and how to reach us.

## Getting help

- Contact your **Security Team**.
- For a full explanation of every check, tap the **help icon** in the add-on sidebar, or see the team guide (`Email-Security-Check-Guide.md`) in this repository.

## What the add-on does

When you open an email in Gmail, a sidebar shows a risk verdict (**Looks clean / Low / Medium / High risk**), any **Red flags**, softer **Good to know** notes, and the **Checks passed**. If something looks wrong, click **Report to Security** to send the original message (with all headers) to the security team for investigation.

**When in doubt, report** — even if the verdict is green.

## Common questions

**The sidebar icon doesn't appear.**
Fully refresh Gmail (close and reopen the tab). The add-on panel is rebuilt on a fresh load.

**A legitimate newsletter shows some "Good to know" notes.**
That's expected. For authenticated marketing mail, common signals (tracking pixels, login links) are shown as low-priority notes rather than red flags.

**I got a High risk result but I think the email is fine.**
Trust the process — report it. The security team will confirm. False alarms are harmless; missed attacks are not.

**Can it delete or block emails?**
No. The add-on only reads the message you have open and, when you choose, emails a copy to the security team. It never deletes, moves, or blocks mail.

## Report a problem

To report a bug or suggest an improvement, email the **Security Team** with a short description and, if possible, a screenshot.
